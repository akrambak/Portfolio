# Product Context

*   **Why this project exists:** To act as Akram Bakhouche's professional shopfront — attract clients/employers and let them read about the work and get in touch.
*   **Problems it solves:** Centralizes profile, skills, PrestaShop module/theme offerings, project examples, and technical writing in one polished, bilingual place.
*   **How it should work:** Visitors browse public pages (Home, About, Modules, Themes, Portfolio, Blog, Contact), switch language (EN/FR) and theme (light/dark), read MDX blog posts, and submit the contact form.
*   **User experience goals:** Fast, animated, responsive, accessible. Smooth route transitions (Framer Motion), no hydration flicker, and a consistent pink-accented visual identity across light and dark modes.
