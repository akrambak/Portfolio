Add MDX syntax highlighting: the Prism light theme is imported and code blocks carry `language-*` classes, but nothing tokenises them yet, so listings render in a single colour — needs a rehype plugin.
*   **Active decisions and considerations:** The re-skin was cheap because every component styles with semantic tokens rather than literal colours — keep it that way. Motion is centralised in `src/lib/motion.ts`; no ad-hoc `transition` objects in pages. `Rule` uses `scaleX` rather than SVG `pathLength` on purpose: `pathLength` animates `stroke-dasharray` and leaves a visibly half-drawn line if interrupted. Large `filter: blur()` layers are banned after they stalled the compositor. Plate geometry must stay deterministic — `Math.random()` there would be a hydration mismatch. Note that Framer Motion runs on rAF, so elements starting at `opacity: 0` remain hidden where rAF never fires (JS disabled or a suspended renderer); worth hardening if no-JS rendering ever matters.
